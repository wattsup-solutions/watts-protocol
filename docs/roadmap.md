# Roadmap: v2.x exploration

> **Status: exploratory and non-normative.** Watts-Protocol™ v2.x is not a finalized protocol specification and is not a Generally Accepted requirement. v1.2 is the established 1.x baseline.

v2.x investigates how governed contextual state might operate continuously across multiple AI systems, agents, tools, projects, and execution environments. Areas under exploration include automated aging, expiration policies, progressive compression, archival, source traceability and provenance, authority scoring, conflict detection, human-override tracking, universal bootstrap capsules, platform translation, context export registries, role-specific context, agent handoffs, multi-agent collaboration, project state engines, context health analysis, and dependency mapping.

## Provisional Layer 0–7 model

The following reference model is intentionally provisional. Its names, boundaries, and structure may be renamed, consolidated, reorganized, or rejected.

- **Layer 0 — Governance & Authority:** human authority, consent, context precedence, provenance requirements, safety boundaries, human override, and rollback principles. It constrains all downstream behavior rather than functioning as simply another processing layer.
- **Layer 1 — Trust, Identity & Capability:** participant and agent identity, capability boundaries, access scope, trust posture, and delegation permissions.
- **Layer 2 — Intent & Mission:** human and project objectives, task scope, constraints, expected outcomes, and success criteria.
- **Layer 3 — Session & Lifecycle Governance:** possible session bootstrap, checkpoint, pause/resume, compression, aging, archival, expiration, and termination mechanisms.
- **Layer 4 — Semantic State:** possible canonical representations of facts, observations, measurements, claims, evidence, decisions, hypotheses, assumptions, inferences, objections, constraints, unresolved questions, risks, and state summaries.
- **Layer 5 — Context Exchange:** potential handoff, synchronization, ordering, provenance, acknowledgement, scope, selective disclosure, evidence-state preservation, and contextual chain-of-custody records. A protocol may define a handoff contract while an implementation platform performs transport.
- **Layer 6 — Agent Collaboration:** possible task delegation, role-specific context, structured critique, preserved dissent, disagreement reconciliation, and controlled escalation among AI agents, AI systems, tools, expert systems, and humans.
- **Layer 7 — Mission Delivery:** possible return of decisions, recommendations, documents, artifacts, completed actions, state updates, unresolved issues, and new risks to the human or governing system.

## Execution substrate

The execution substrate remains separate from the proposed layer model. It may include models, agent runtimes, APIs, databases, vector stores, search systems, tools, services, and cloud infrastructure. These technologies execute, store, retrieve, or transport information; the exploratory protocol model concerns governance and continuity rules applied to contextual state.

## Candidate modules

Candidate future modules include Session Governance; Memory and Context State; Evidence-State Integrity; Structured Negotiation; and Audit, Provenance, and Contextual Chain of Custody. These concepts remain under evaluation and should not be represented as released functionality or requirements.
